CIRCUIT CLASS PLANNER — VERSION 1

TO OPEN LOCALLY: Open index.html in Chrome/Edge (some browser security settings limit local storage when opened from files).

TO PUBLISH ON GITHUB PAGES:
1. Create a NEW repository (or use your circuit planner repository).
2. Upload ALL files from this ZIP to the repository ROOT: index.html, data.js, icon.svg, manifest.webmanifest, sw.js.
3. In Settings > Pages select Deploy from a branch, main, / (root), Save.
4. Open the GitHub Pages address for THIS repository. Install via browser menu > Add to Home Screen / Install App if offered.

IMPORTANT: Keep all files together. Saved classes and custom exercises live in this browser's local storage; export a JSON backup regularly. Import it on another device to move your data. Online exercise discovery opens web searches for review and manual entry; it does not automatically scrape third-party sites.

Timer: Keep screen awake during class where possible. Backgrounded mobile browsers can suspend timers or audio. The timer uses elapsed real time to correct drift while active.
